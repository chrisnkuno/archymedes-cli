# Internationalization

Archymedes CLI localizes its control surfaces into **16 languages**, chosen for global reach with
deliberate weight on the Americas and Asia:

`en` English · `es` Español · `pt` Português · `fr` Français · `de` Deutsch · `ru` Русский ·
`ar` العربية · `tr` Türkçe · `zh` 中文 · `ja` 日本語 · `ko` 한국어 · `hi` हिन्दी · `bn` বাংলা ·
`ur` اردو · `id` Bahasa Indonesia · `vi` Tiếng Việt

Select one with `archymedes --language <code>`, `ARCHYMEDES_LANGUAGE=<code>`, or from `/settings`.
An unset language falls back to the host locale (`LANG`), then to English. A locale variant
(`pt-BR`, `zh_CN`) resolves to its base.

## What is translated

`src/i18n.ts` is the catalog. Every language has:

- **Control labels** (`LABELS`) — the words on the prompt tagline, the settings menu, `/keys`.
- **Slash-command descriptions** (`COMMANDS`) — the right-hand column of `/help`'s in-session list.
- **Keyboard-shortcut descriptions** (`TRANSLATED_KEYBOARD_IDS`) — keyed by shortcut id, not row.
- **Core messages** (`MESSAGES`, via `t()`) — the `--help` page's section headers and tagline, the
  mode labels on the prompt, the first-run "not configured" line, and the connectivity doctor's
  header and verdicts.

A key a language has not translated renders its English source — never an empty string. This is
enforced by `i18n.test.ts`.

## What is not translated yet

These stay English and are the next tranche of work:

- The **dense flag-reference rows** in `--help` (`archymedes --json "task"`, `--sandbox-minutes N`,
  …). The section headers around them are localized; the one-line descriptions are not.
- The **`/guide`** topic prose (`src/guide.ts`) — 17 multi-paragraph topics.
- `/settings` **field labels** beyond the menu chrome.
- Low-frequency **runtime status, approval, and error** strings scattered through `src/archymedes.ts`.
- **Defender / security** long-form copy.

## Adding a language or a key

1. Add the code + display name to `CONTROL_LANGUAGES`.
2. Fill `LABELS`, `COMMANDS`, `TRANSLATED_KEYBOARD_IDS`, and the `MESSAGES` entries for it.
3. `bun run test` — `i18n.test.ts` fails until every language has label + command + shortcut cover.

The six most recently added languages (`ja ko de id vi tr`) were machine-translated and are pending
native review.
