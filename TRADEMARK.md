# Trademark and name-use policy

The Apache License 2.0 that covers this code does **not** grant any rights to the
"Archymedes", "Archymedes CLI" and "Friday" names, the `@archymedes` npm scope, the wordmarks, or
the project's logos and visual identity. Those are reserved by the project.

## The marks

- **Archymedes** and **Archymedes CLI** — the project and organisation names, and their wordmark.
- **Friday** — the name of this command-line coding agent as distributed by the project (the
  `friday` command, the "Friday" wordmark, and the product as presented in its interface and docs).
- **`@archymedes`** — the npm scope. Only the project publishes under it; packages such as
  `@archymedes/friday` and `@archymedes/friday-<os>-<arch>` are official builds.

## You may, without asking

- Fork, modify, redistribute and build commercial products on the source code, per the license.
- State factually that your product "is built on", "is based on", "uses" or "is a fork of"
  Archymedes CLI or Friday, in plain prose.
- Keep the names in unmodified files, commit history, and the `NOTICE` file.
- Keep the `friday` command name inside a private, unredistributed build for your own use.

## You may not, without written permission

- Call a modified or redistributed build "Archymedes", "Archymedes CLI", "Friday", or any name
  confusingly similar, or ship it under the project wordmarks or logo.
- Use the names or marks for your product name, package name, domain, org name, or in a way
  that implies the project endorses, sponsors, or maintains your version.
- Publish packages under the `@archymedes` npm scope, or under a name that imitates it.
- Use the marks on merchandise.

If you distribute a modified build, give it your own name (and your own command and package
names) and make clear it is not the official project. Questions: open an issue.
